# BIOSTAT-721-Project-2

Project's purpose: to conduct exploratory data analysis and examine the associations between various air pollutants taken from the air pollution monitor at the RDU airport.  
Data source: the data came from the EPA monitor at the RDU airport for the year 2018, 2019, and 2020; the years 2018 and 2019 contains data for January - December, while the year 2020 only contains data from January - April.   
File structure:  
How to reproduce: For this project. I used the version 2.0.0 of the tidyverse package, version 1.2.1 of the dplyr package, version 1.4.0 of the gt package, version 1.9.5 of the lubridate package, and version 4.0.3 of the ggplot2 package. I am also running R version 4.5.1 (2025-06-13 ucrt).
